# Submission Documents

Place the required submission files in this folder, renamed with your team name (replace `TeamName`):

| File | Purpose |
| --- | --- |
| `SDC2026_TeamName_Preliminary.pdf` | Preliminary submission |
| `SDC2026_TeamName_TechDeclaration.pdf` | Technology declaration |
| `SDC2026_TeamName_Replit_POU.pdf` | Replit proof of use |
| `SDC2026_TeamName_Runpod_POU.pdf` | RunPod proof of use |

The blank templates are in the hackathon's Google Drive folder — download them, fill them in, and commit the completed PDFs here.
